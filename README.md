
# CRUD API — Product Catalog

A simple CRUD API for a Product Catalog built with **Fastify** and **TypeScript**, using an in-memory database.

## Requirements

- Node.js 24.x.x
- npm

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Vietta7/CRUD-API.git
cd CRUD-API
```

2. Install dependencies:

```bash
npm install
```

3. Create `.env` file from the example:

```bash
cp .env.example .env
```

## Running the Application

**Development mode** (with auto-reload):

```bash
npm run start:dev
```

**Production mode** (builds and runs compiled JS):

```bash
npm run start:prod
```

**Multi-process mode** (horizontal scaling with load balancer):

```bash
npm run start:multi
```

In multi-process mode:
- Load balancer starts on `http://localhost:PORT` (default: 4000)
- Workers start on `PORT+1`, `PORT+2`, ... (number of workers = available CPU parallelism - 1)
- Requests are distributed using **Round-Robin** algorithm
- Database state is **synchronized** between all workers

## Running Tests

```bash
npm test
```

Runs 6 test scenarios covering the full CRUD lifecycle.

## API Reference

Base URL: `http://localhost:4000`

### Get all products

```
GET /api/products
```

Response `200`:
```json
[
  {
    "id": "9b0b57ff-356a-453d-b62b-6dd52a73da0a",
    "name": "Laptop",
    "description": "Gaming laptop",
    "price": 999.99,
    "category": "electronics",
    "inStock": true
  }
]
```

---

### Get product by ID

```
GET /api/products/:productId
```

| Status | Description |
|--------|-------------|
| 200 | Product found |
| 400 | Invalid UUID format |
| 404 | Product not found |

---

### Create a product

```
POST /api/products
```

Request body:
```json
{
  "name": "Laptop",
  "description": "Gaming laptop",
  "price": 999.99,
  "category": "electronics",
  "inStock": true
}
```

| Status | Description |
|--------|-------------|
| 201 | Product created successfully |
| 400 | Missing or invalid fields |

---

### Update a product

```
PUT /api/products/:productId
```

Request body — same fields as POST.

| Status | Description |
|--------|-------------|
| 200 | Product updated successfully |
| 400 | Invalid UUID or invalid fields |
| 404 | Product not found |

---

### Delete a product

```
DELETE /api/products/:productId
```

| Status | Description |
|--------|-------------|
| 204 | Product deleted successfully |
| 400 | Invalid UUID format |
| 404 | Product not found |

## Product Schema

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| id | string (UUID) | auto | Generated by server |
| name | string | yes | — |
| description | string | yes | — |
| price | number | yes | Must be > 0 |
| category | string | yes | e.g. "electronics", "books" |
| inStock | boolean | yes | — |

## Usage Examples

**Create a product:**
```bash
curl -X POST http://localhost:4000/api/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Laptop","description":"Gaming laptop","price":999.99,"category":"electronics","inStock":true}'
```

**Get all products:**
```bash
curl http://localhost:4000/api/products
```

**Get by ID:**
```bash
curl http://localhost:4000/api/products/9b0b57ff-356a-453d-b62b-6dd52a73da0a
```

**Update a product:**
```bash
curl -X PUT http://localhost:4000/api/products/9b0b57ff-356a-453d-b62b-6dd52a73da0a \
  -H "Content-Type: application/json" \
  -d '{"name":"Updated Laptop","description":"Updated desc","price":1200,"category":"electronics","inStock":false}'
```

**Delete a product:**
```bash
curl -X DELETE http://localhost:4000/api/products/9b0b57ff-356a-453d-b62b-6dd52a73da0a
```
